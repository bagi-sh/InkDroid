# Android E-Reader Transformation Project 

Este projeto dedica-se à técnica de **ressignificação de hardware**, especificamente focada na transformação de tablets Android 11 antigos em dispositivos minimalistas para leitura de e-books.

Utilizando o **Android Debug Bridge (ADB)**, automatizamos a remoção de pacotes desnecessários (bloatware) para maximizar o desempenho e a autonomia de bateria de dispositivos com hardware limitado.

## Funcionalidades

- **Debloat Seletivo**: Remoção de serviços de telemetria, redes sociais e aplicativos pré-instalados.
- **Otimização de Recursos**: Scripts para desativar animações e processos de segundo plano.
- **Ambiente de Leitura**: Configurações sugeridas para transformar a interface em um ambiente livre de distrações.

## Pré-requisitos

Antes de iniciar, certifique-se de possuir:
- Um dispositivo Android com a **Depuração USB** ativada.
-  Cabo de dados de boa qualidade para a conexão.
